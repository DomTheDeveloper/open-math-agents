# The first failure of Sun's third A234360 conjecture

Let $\varphi$ denote Euler's totient and put $C(n,k)=k(k+1)^{\varphi(n-k)}+1$. Zhi-Wei Sun conjectured that for every integer $n>1$ there is a $k$ with $0<k<n$ for which $C(n,k)$ is prime. Dev Pratap Singh found the first counterexample at $n=7588$. This independent computation verifies both the failure at 7588 and the existence of a prime for every smaller admissible input. [Original conjecture](https://oeis.org/A234360) · [Singh's witnesses and formalization](https://github.com/DevSingh05/oeis-a234360/tree/2dd137006c176c1b8780f50452e9a102f695d80c)

## Why every candidate at 7588 is composite

The certificate covers every integer $k$ from 1 through 7587, in order. For 6,453 candidates, a supplied integer $d$ satisfies $1<d<C(7588,k)$ and divides $C(7588,k)$. For the other 1,134, setting $m=C(7588,k)$ gives $m>2$ and $2^{m-1}\not\equiv1\pmod m$. Fermat's little theorem proves that each of those $m$ is composite. For example, $C(7588,7587)=57\,570\,157=1249\cdot46\,093$. [Witness lists in the Lean source](../proofs/OeisA234360.conjecture_3.lean) · [Exact-arithmetic checker](../tools/verify_oeis_a234360_7588.cpp)

## Why 7588 is the first failure

For each of the 7,586 integers $2\le n<7588$, the certificate records a triple $(n,k,a)$. Singh supplied the values of $k$. The independent calculation found a base $a$ and verified the following conditions on $m=C(n,k)$.

$$
a^{m-1}\equiv1\pmod m,\qquad
a^{(m-1)/q}\not\equiv1\pmod m
\quad\text{for every prime }q\mid m-1.
$$

The identity $m-1=k(k+1)^{\varphi(n-k)}$ gives all the required primes by trial division of $k$ and $k+1$. The first congruence makes $a$ a unit with order dividing $m-1$. If its order were a proper divisor, it would divide $(m-1)/q$ for some prime $q\mid m-1$, contradicting the second congruence. Thus the powers of $a$ give $m-1$ distinct units modulo $m$. Every nonzero residue is a unit, so $m$ is prime. The largest base needed across all 7,586 rows was 77. [Certificate table](../tools/sun_7588_prime_witnesses.tsv) · [Primality checker](../tools/prove_7588_minimal.cpp)

## Extending the search through 9,000

An independent search found a pair $(k,a)$ for each of the next 1,412 inputs, $7589\le n\le9000$. The same full-order test proved all 1,412 chosen values prime. The largest base in this range was 58. Together with the preceding checks, this proves that **7588 is the only counterexample for $2\le n\le9000$**. [Additional certificates](../tools/sun_after_7588_prime_witnesses.tsv)

## Reproduce the checks

From the root of this revision, use a C++17 compiler with OpenMP and GMP's C++ bindings.

~~~sh
c++ -O3 -std=c++17 -fopenmp tools/verify_oeis_a234360_7588.cpp -lgmpxx -lgmp -o verify7588
OMP_NUM_THREADS=3 ./verify7588 proofs/OeisA234360.conjecture_3.lean
c++ -O3 -std=c++17 -fopenmp tools/prove_7588_minimal.cpp -lgmpxx -lgmp -o minimal
OMP_NUM_THREADS=3 ./minimal tools/sun_7588_prime_witnesses.tsv > replay.tsv
cmp tools/sun_7588_prime_witnesses.tsv replay.tsv
OMP_NUM_THREADS=3 ./minimal tools/sun_after_7588_prime_witnesses.tsv 7589 9000 > after.tsv
cmp tools/sun_after_7588_prime_witnesses.tsv after.tsv
~~~

Both exhaustive conclusions above were checked with exact integer arithmetic. The local Lean 4.33.1 kernel also checked the compositeness argument for 6,480 of the 7,587 candidates. The full run of the single-file Lean port reached the local memory limit.
